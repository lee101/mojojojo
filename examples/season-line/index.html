Season Line

Paste a season as W/L/D characters (or numbers) and get record, win %, last-5 form, best/worst runs and a simplified rating — computed by Mojo-compiled kernels.

The kernels

def best_run(results: list[float]) -> int:
    best = 0; cur = 0
    for i in range(len(results)):
        if results[i] > 0.0:
            cur += 1
            if cur > best: best = cur
        else: cur = 0
    return best

Branchy scalar loops over a small buffer — exactly the compile shape. The W/L string parsing stays in the handler.
