Worldline

Our-World-in-Data-style explorer: pick a metric, rank countries by growth, draw the lines. The growth/CAGR kernels compile to native Mojo via mojosub; the table and chart are plain browser code.

Demo data is synthetic but shaped like real series (NZ/US/DE/JP/ BR/IN/KR/ZA …). Paste real series via the API: POST /api/explore {"countries": {"NZ": [...], "US": [...]}}. No live fetch — no terms-of-service trap, and the example stays free to run.
