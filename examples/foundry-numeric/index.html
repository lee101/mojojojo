Train a tiny model. Take the artifact with you.

A bounded nearest-centroid classifier for binary numeric datasets. CPU-only, 512 rows per split, 32 features. This is a baseline deployment example, not zero-shot AI or a validated Foundry model.

Calls require your mojojojo API key and use your compute credits. Do not paste API keys into this page; call from your own terminal.

Train

POST ./api/model
Authorization: Bearer YOUR_API_KEY
Content-Type: application/json

{"operation":"train","dataset_revision":"your-immutable-revision",
 "data_license":"your-data-license",
 "train":{"rows":[[0,0],[1,1],[9,9],[10,10]],"labels":[0,0,1,1]},
 "validation":{"rows":[[2,2],[8,8]],"labels":[0,1]}}

The response downloads as model.json and records split hashes, validation accuracy and runtime. The sample data is synthetic; it provides no benchmark evidence. Keep your test split hidden.

Infer

{"operation":"infer","model":MODEL_JSON_MODEL_FIELD,"rows":[[3,3]]}

Only JSON numeric models are accepted. No pickle, executable model code, provider credentials or automatic publication.
