mojosub compiles a deliberately small, typed numeric subset of Python to Mojo. Refusing unsupported code is part of the trust model, not a missing marketing checkbox.

Everything else keeps a real CPython path. When an agent writes the Mojo version, its output must compile, agree with CPython on generated inputs, and be measurably faster before it is accepted.
